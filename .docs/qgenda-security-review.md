# QGenda milestone 1 security advisory review

Reviewed October 2, 2026. `mix hex.audit` succeeded with no retired packages;
this checks retirement, not comprehensive vulnerabilities. Current OSV querybatch
covered all 47 resolved Hex dependencies and returned zero matches. Current OSV
queries for documented vendored Shepherd 13.0.3, topbar 3.0.0 and DaisyUI 5.0.35
also returned zero matches. A Heroicons React 2.2.0 query returned zero but is only
a proxy for the Git SVG dependency. Unversioned embedded components and unpublished
issues remain outside that evidence. No Hex upgrade was required.

The expanded runtime review used the official GitHub API
`https://api.github.com/repos/erlang/otp/security-advisories?per_page=100`.
The local runtime is **OTP 29.0.1**, with the component versions below.
These pre-existing runtime findings are outside the Hex dependency scan.
Production's exact runtime has not been verified; CI/deploy originally specified
only OTP major 27. Patched supported branches are **29.1.1, 28.5.0.7,
or 27.3.4.18** for the entire set reported here. Installing/updating the shared
host runtime and verifying production runtime are separate from the XLSX parser.
No runtime upgrade is claimed by this report.

The latest official advisory publication in the retrieved response is September
22, 2026, preceding this review. The existing `erlef/setup-beam@v1` configuration
uses its default loose matching for OTP `27`; a fresh CI run is expected to
select the latest available matching release, but no CI run or production
runtime was inspected here. Confirm the resolved version is at least 27.3.4.18
on that branch. The action itself recommends exact versions with strict
matching when reproducibility is required; see its
[version selection documentation](https://github.com/erlef/setup-beam#input-versioning).

Critical TLS client authentication bypass GHSA-rgxr-4g4w-j875 can affect ordinary
outbound TLS 1.3, including verify_peer; a malicious server or on-path attacker
can bypass certificate validation. This is not limited to the preview feature.

The new reader uses bounded in-memory inflation, safe paths, no disk extraction,
no dynamic XML atoms, explicit DTD/entity rejection, XML depth/node limits,
formula rejection, and no external relationship resolution. The ZIP traversal
finding therefore does not describe the new reader's extraction path.
