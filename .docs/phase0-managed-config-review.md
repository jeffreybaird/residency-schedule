## Required contract

Review covers the complete current `config/runtime.exs` input surface and release node/distribution/cookie settings. Required target and expected-database declarations must agree with the deployment destination and parsed database URL. They are configuration guards, not proof of database permissions or of where GitHub resolved a value.

Configuration must travel as structured JSON from step environment variables into a private local file, through a separate transfer, and into mode-700 host configuration versions containing mode-600 JSON and systemd environment files. Secrets must not enter command arguments, SSH script interpolation, code artifacts or logs. Artifact and configuration validation precede active application/configuration mutation. Optional settings use explicit disabled/default values and clear removed credentials rather than merging old configuration or inheriting ambient tokens.

Migration and demo seeding use a structured Ruby process environment, never shell sourcing of incoming JSON or legacy `.env` files. Environment-file quoting must preserve literal quotes, backslashes, dollar expressions and backticks without execution; NUL, CR and LF are rejected. Legacy cookie inspection accepts only a defined literal subset and fails generically on ambiguous syntax. GitHub's required cookie must match the current effective cookie without implicit generation or rotation.

Managed environment symlinks require strict containment, layout and sidecar agreement. Rollback must restore the preceding configuration with the preceding application. Retained versions include the first legacy regular environment file and its applicable cookie, with code/deployment association metadata for future operator recovery. No pruning or complete operator rollback capability is assumed.

The earlier 22 deployment contracts must remain covered, with fixtures adapted to the intentionally complete-replacement configuration model. New regressions must exercise validation failures, literal handling, cookie continuity, optional clearing, legacy non-execution, private transfer/cleanup, contained sidecars and configuration rollback/retention. Ruby style review checks the existing helper and new code without adding a Gemfile, disabling cops or claiming an unavailable formatter ran.
